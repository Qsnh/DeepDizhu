# DeepDizhu 四人斗地主

用 [MyGo](https://mygo.egoist.dev/docs) 的原生 UI（纯 Go，GPU 绘制，无 WebView）写的四人斗地主桌面游戏：你和三位电脑玩家同桌，每位电脑玩家的水平可以单独设置为简单、普通或困难。

## 运行

需要 Go 1.27 及以上（`go` 命令会按 `go.mod` 自动下载工具链）。

```sh
go tool mygo dev      # 开发运行，改代码自动重启
go tool mygo build    # 打包，输出到 build/<os>-<arch>/
CGO_ENABLED=0 go test ./...   # 全部测试，界面测试无需窗口
```

查看界面截图（无需打开窗口）：

```sh
mkdir -p /tmp/ddz && SNAPSHOTS=/tmp/ddz go test -run 'Lobby|Play|Selection' .
```

在真实窗口里让程序自己打一局并截图（检查后台线程与窗口刷新）：

```sh
mkdir -p /tmp/ddz && SMOKE_SHOTS=/tmp/ddz go run -tags smoke .
```

重新生成应用图标：`go run ./tools/icon`。

## 玩法

- 两副牌 108 张，每人 25 张，留 8 张底牌。
- 叫分：从首家起依次叫 1、2、3 分或不叫，须比之前叫得高；叫 3 分立即成为地主，否则一轮后最高者当地主；无人叫则重新发牌。地主拿走底牌并先出。
- 牌型：单张、对子、三张、三带一、三带一对、顺子（≥5，3 到 A）、连对（≥3 对）、飞机（≥2 组连续三张，可带单或带对）、四带二（两单或两对）、炸弹（4～8 张同点，张数多者大）、天王炸（四张王，最大）。
- 计分：倍数 = 叫分 × 2^炸弹数，春天 / 反春再 ×2，不超过设置的封顶（默认 64 倍）。地主赢得三份 底分×倍数，农民各输一份；反之亦然。
- 出牌有多种理解时（如 333444555666），领出取最自然的一种：炸弹优先，其次链最长、主点数最大；跟牌时取能压过上家的一种。

## 电脑玩家

| 水平 | 做法 |
| --- | --- |
| 简单 | 随机出合法的牌，偏向小牌；能压时约三成概率不压；不看队友。 |
| 普通 | 按手牌强度叫分；把手牌拆成最少手数的组合（保留炸弹、抽出顺子/连对/飞机），先出最弱的组；跟牌用最小且不拆好结构的牌；不压队友（除非能借此走完，或要拦截只剩 1～2 张的地主）；对手快出完时改出对子等并用大牌拦单张。 |
| 困难 | 在普通的基础上记牌，并做确定化蒙特卡洛搜索：对前若干个候选出法，按各家剩余张数（以及地主手里尚未打出的底牌）随机还原其他人的手牌，用快速策略把整局模拟打完，选平均结果最好的一手。每步约 0.5 秒预算、最多 6 万次模拟，用最多 4 个线程。 |

自动对战（同一副牌两队互换各打一次）的胜率：普通对简单 99.5%，困难对普通 57.5%（测试为省时把困难限制在每步 1500 次模拟；游戏里默认约 1.4 万次，此设置下的胜率没有单独测量），困难对简单 99.5%。四人斗地主里地主一方本身占优：双方都是普通水平时地主约赢 76%。

操作：

- 点击手牌选中 / 取消，按住拖过多张牌可一次选中，右键清空选择。
- 「提示」依次给出能出的牌；「出牌」只在所选的牌合规时可用，旁边会显示牌型。
- 顶栏「设置」可改电脑水平（立即生效）、出牌速度、底分与封顶（下一局生效）、记牌器开关，以及清零积分重新开始。
- 设置与累计积分保存在系统的应用数据目录（macOS 为 `~/Library/Application Support/DeepDizhu/deepdizhu.json`）。

## 代码结构

| 路径 | 内容 |
| --- | --- |
| `game/` | 规则引擎：牌、牌型识别与比较、出牌生成、叫分与出牌流程、计分 |
| `ai/` | 电脑玩家：简单 / 普通 / 困难三个水平，以及给你的「提示」 |
| `table.go` | 牌桌状态与流程控制：发牌、轮到电脑时在后台思考、结算 |
| `view.go`, `card.go`, `dialogs.go` | 原生 UI：牌桌、牌面、大厅、设置、规则与结算弹窗 |
| `palette.go` | 配色与字体（漆器风格：黛蓝桌面、铜边、象牙牌面、朱砂地主印） |
| `store.go` | 设置与积分的保存 |
| `main.go` | 窗口与后台线程调度 |
